## User Interaction

### Analysis

- Identifizieren von Schlüsselelementen eines externen Auftrags inklusive Klärungen mit Kunden, Endnutzern und Experten.
- Identifizieren von Kunden- und Endbenutzerbedürfnissen sowie deren Umsetzung in ICT-Ressourcen
- Erkunden von bestehenden interaktiven Konzepten, Diensten und Produkten

### Design

- Übersetzen von Empfehlungen in eine einfache Benutzerinteraktion durch einen vorgegebenen Interaktionsprozess, z. B. unter Verwendung einer StandardPrototyping-Technik.
- Entwerfen eines Tests, mit dem wesentliche Interaktionsprobleme identifiziert werden können.
- Entwerfen einer Visualisierung eines einfachen Datensatzes.

### Implementation

- Realisieren und testen von einfachen interaktiven Produkten oder Dienstleistungen auf der Grundlage eines Interaktionsdesigns unter Verwendung von Standardtools, Barrierefreiheitsrichtlinien und/oder Corporate Identity
